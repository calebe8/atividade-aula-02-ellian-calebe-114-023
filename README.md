# Evangelion Geek

Página institucional criada como atividade avaliativa da disciplina de Desenvolvimento Web e Mobile (Aula 02 — HTML do zero).

O projeto apresenta uma página fictícia sobre o anime **Neon Genesis Evangelion**, explicando a história, as versões existentes e onde assistir.
## Estrutura do projeto

```
atividade-aula-02-ellian-calebe/
├── index.html
└── assets/
    ├── style.css
    └── eva.jpg
```

## Como visualizar

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/atividade-aula-02-ellian-calebe.git
   ```
2. Abra o arquivo `index.html` diretamente no navegador.

## Seções da página

| Seção | Conteúdo |
|---|---|
| **Versões** | As diferentes versões de Evangelion (mangá, anime, filme, rebuilds) |
| **Plataformas** | Onde assistir a cada versão (Netflix, Prime Video) |
| **Contato** | Informações de contato fictícias |
